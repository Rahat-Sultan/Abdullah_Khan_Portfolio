# Abdullah Khan — Galactic Portfolio

Public site for **Abdullah Khan**, Digital Marketing Specialist.

## Stack (free tiers)

- Next.js (App Router) + React + TypeScript
- Tailwind CSS v4
- Vercel (deploy)
- Supabase (auth, database, storage) — wired in later Kiro phases
- Cursor (foundation) / Kiro (remaining phases)

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
